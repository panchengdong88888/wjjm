### 3. 工厂的可读等价表达（变量名是语义适配名）
```lua
local function ButtonFactory(config, rowIndex, groupOffset)
    local button = GUI:Button_Create(
        uiParent,
        config.key,
        baseX - 85 * rowIndex,
        baseY + groupOffset,
        "res/public/fuzhu_btn.png"
    )
    if not button then return nil end

    buttonMap[config.key] = button
    buttonMap[config.key .. "Cfg"] = config

    GUI:Button_setTitleText(button, config.name)
    GUI:Button_setTitleFontSize(button, 18)
    GUI:Button_setTitleFontName(button, "res/public/kaiti2.ttf")
    GUI:Button_setTitleColor(button, "#ffffff")

    if config.toggle then
        config.toggled = false
    end

    GUI:addOnClickEvent(
        button,
        MakeButtonClickClosure(callbackMap, config, button)
    )
    return button
end
```

## 三、root/52/32/0点击闭包（48槽，0个显式参数，3项捕获）

捕获顺序：
- H[0] = callbackMap；
- H[1] = 当前config；
- H[2] = 当前button。

已闭合行为：
1. 读取 `callbackMap[config.key]`。
2. 如果回调存在，调用它；如果返回值严格等于false，立即退出，不切换toggle状态，也不更新按钮标题/颜色。
3. 如果回调不存在，则跳过业务回调调用段，但继续检查config.toggle；因此原始闭包允许“没有业务回调的toggle配置”仍执行外观/状态切换。
4. 若config.toggle为假值，退出，不切换状态。
5. 若config.toggle为真值，执行 `config.toggled = not config.toggled`。
6. 标题：toggled为真时使用config.toggle，否则使用config.name。
7. 颜色：toggled为真时使用 `#ff0000`，否则使用 `#ffffff`。
8. 通过GUI.Button_setTitleText和GUI.Button_setTitleColor更新同一个捕获button。

可读等价表达：
```lua
local function ButtonClick()
    local callback = callbackMap[config.key]
    if type(callback) == "function" then
        if callback() == false then
            return
        end
    end

    if not config.toggle then
        return
    end

    config.toggled = not config.toggled
    GUI:Button_setTitleText(
        button,
        config.toggled and config.toggle or config.name
    )
    GUI:Button_setTitleColor(
        button,
        config.toggled and "#ff0000" or "#ffffff"
    )
end
```

## 四、与当前唯一正式版对照

正式版SHA仍为 `9e780845979473dd23e032f3d169657d08ce7c2a`，本轮没有修改。

已匹配：

- 坐标公式 `baseX - 85*rowIndex`、`baseY + groupOffset`。
- Button_Create纹理、按钮标题、18号字号、字体路径、白色初始颜色。
- toggle配置初始toggled=false。
- 点击回调存在且返回非false时切换toggled、标题和红/白颜色。
- 子闭包捕获callbackMap/config/button顺序正确。

发现需处理的语义差异：
1. 原始工厂在callbackMap为表时，无论callbackMap[config.key]当前是否为函数，都会注册点击闭包；正式版make_helper_root_52_32目前仅在该key对应函数时注册事件。
2. 原始点击闭包在业务回调缺失时，会跳过回调调用但继续执行toggle外观逻辑；正式版helper_root_52_32_0在callback不是函数时直接return。因此“toggle配置但业务回调缺失”的边界行为不一致。
3. 原始工厂明确写入 `buttonMap[config.key .. "Cfg"] = config`。正式版工厂只写入 `visibleItems[config.key]=button`；正式版另建 `buttonConfigByKey` 映射，但尚未证明它与原始H[3]是同一对象/同一用途。先追踪H[3]父级捕获别名，再决定是否补齐该字段，不擅自合并两个表。
4. 原始root/52/32无条件调用GUI:addOnClickEvent（依赖父级提供的callbackMap表）；正式版增加了callbackMap类型及单个回调函数存在性判断。第1项已记录其可观察差异。
