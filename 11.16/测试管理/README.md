# 11.16 测试管理入口

本目录是 11.16 模块恢复与游戏 UI 加载故障排查的唯一测试管理入口。

## AI 接手时只读这几份文件

1. `../00_项目入口.md`：项目范围、权威源码、禁止事项。
2. `00_测试总控.md`：当前测试状态与阶段结论。
3. `03_下一步唯一任务.md`：当前唯一允许推进的任务。
4. `01_测试历史台账.md`：只查看需要确认历史测试结果时。
5. `04_AUDIT-LOAD-FULLCHUNK-001静态核验记录.md`：当前加载层静态证据。

**禁止**每次接手就遍历`测试版本库`、逐个读取所有Lua测试文件，或重复已经完成的实机测试。只有当前任务明确引用某个测试编号/文件时才读取它。

## 目录说明

- `当前测试/`：当前唯一等待用户实机验证的文件。
- `测试版本库/UI隔离测试/`：历史UI隔离测试快照。
- `测试版本库/UI批量诊断/`：G19–G52等历史批量诊断快照。
- `测试版本库/UI对照测试/`：整合/对照测试快照。
- `测试版本库/main与加载层测试/`：G53–G57及其他main/加载层测试。
- `测试版本库/文件索引.csv`：文件路径、Blob SHA和分类；用于按需定位，不代表测试通过。

## 永久规则

- 唯一正式明文：`../MainLeftBottom_11.16_明文.lua`。不得用测试副本覆盖。
- 每次只允许一个明确的测试变量；测试文件必须从指定基线复制并记录差异。
- 测试文件先通过Lua 5.1/5.4语法检查，再交给用户实机测试。
- 实机结果只记录用户原话；没有用户反馈一律标记为“未测试”，不能推断通过。
- 不得重测已确认结果，不得把不同分支/不同编号的测试混为一谈。
- 任何移动/整理只改变路径，不改Lua文件内容；历史版本保留，不随意删除。
