## 二、UI字段/状态与入口关系

- `a.hide`/`a.show`/`a.destroy`分别指向DestroyUI、SetButtonVisibilityState、ShowHideAllButtons；捕获对象依次为[a,timerState,b]、[a,b]、[timerState,b,a]。
- `a.blacklist`与blacklistState是同一个表；UI距离保存回调写入其distance，BlacklistPlayerDetection读取同一字段。
- `a.onDamageMsg`指向onDamageMsg；InstallDamageHook包装消息处理器时从同一a表动态读取该回调。
- `MainLeftBottom.main`指向AccountIDValidation；`MainLeftBottom.doInit`指向doInit_UI，AccountIDValidation等待回调在主界面面板出现后调用doInit。
- `a.hidebut`由doInit_UI写入；隐藏按钮回调读取同一字段，ShowHideAllButtons负责隐藏并清空该字段。
- `a.resWin`与timerState.resTimer由资源统计窗口闭包共享；关闭/销毁路径取消同一resTimer并清理句柄。
- `featureState`严格等于z；采集/存仓/取物/丢弃/黑名单相关状态位均由对应功能闭包读写，不另建副本。
- `buttonMap`严格等于b；createButton写入按钮句柄，UI可见性和清理闭包遍历同一映射表。
