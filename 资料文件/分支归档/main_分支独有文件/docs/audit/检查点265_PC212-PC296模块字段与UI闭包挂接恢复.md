## 三、发现并保留的PC275特殊语义

root字节码在PC275重新读取`_ENV.MainLeftBottom`，并非单纯继续使用PC1保存的模块根表寄存器。

此前恢复适配器直接将AccountIDValidation写入`rootModule.main`，虽然正常加载时全局对象应与原表一致，但这省略了PC275显式重读动作。现在改为：
- PC275：`local accountValidationModule = _G.MainLeftBottom`
- PC276-PC278：创建AccountIDValidation并按T[4]/T[5]捕获
- PC279：`accountValidationModule.main = rootPrototypes.AccountIDValidation`

没有擅自将accountValidationModule强制等同于rootModule；若宿主在模块初始化过程中替换了全局MainLeftBottom，适配代码保留PC275的实际读取语义。最终PC412返回的仍是原root模块表。
