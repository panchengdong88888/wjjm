# 检查点251：UI闭包共享模块表装配

日期：2026-11-10

## 本批源码装配

将三个已有完整静态函数主体的捕获工厂实例化到根模块装配器：

| 原型 | 捕获顺序 | 装配结果 |
|---|---|---|
| root.children[37] DestroyUI | T[0], T[3], T[1] | MainLeftBottom.hide |
| root.children[10] SetButtonVisibilityState | T[0], T[1] | MainLeftBottom.show |
| root.children[40] ShowHideAllButtons | T[3], T[1], T[0] | MainLeftBottom.destroy |

## 捕获对象核对

- T[0]：MainLeftBottom.a。根模块初始化时创建，包含isHidden、hidebut、Blocklist、SendHookList、RecvHookList等字段；三个闭包均需同一状态表引用。
- T[1]：MainLeftBottom.b。根模块初始化时创建的按钮映射表；三个闭包中按相应upvalue顺序引用同一表。
- T[3]：timerState。根模块PC42创建的定时器状态表；DestroyUI处理resTimer，ShowHideAllButtons处理rewardTimer和cruiseTimer。
- 这三项都是稳定表引用，不需要额外标量cell包装；装配器从rootSource导出字段获取对象，避免重新创建副本。

## 函数行为保持

- DestroyUI：清除isHidden；如resTimer存在则SL:UnSchedule并置nil；清resWin；调用GUI:Win_CloseAll；遍历buttonMap并逐项GUI:setVisible(..., true)。
- SetButtonVisibilityState：设置isHidden=true；遍历buttonMap并逐项显示控件。
- ShowHideAllButtons：分别取消rewardTimer与cruiseTimer并清nil；遍历buttonMap显示控件；hidebut存在时隐藏并清nil。

## 模块字段

依据root PC265/269/274的写入事实：
- MainLeftBottom.hide = DestroyUI
- MainLeftBottom.show = SetButtonVisibilityState
- MainLeftBottom.destroy = ShowHideAllButtons

不将这三个闭包错误导出为全局函数。
