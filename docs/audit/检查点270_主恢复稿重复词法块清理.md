# 检查点270：主恢复稿重复词法块清理

日期：2026-11-10  
仓库：panchengdong88888/wjjm / main

## 一、本批目的

对`04_源码候选/MainLeftBottom_恢复源码.lua`进行源码整合清理。此前同一来源文件曾多次以内嵌`do ... end`词法块注册到`MainLeftBottomRecovered.sources`；后注册版本会覆盖先注册版本，造成旧代码继续执行定义、重复注册和过期注释留存。

本批只删除已被后续版本完整覆盖的旧词法块，不修改保留版本的函数体业务逻辑，不提升静态恢复/运行时验证计数。
