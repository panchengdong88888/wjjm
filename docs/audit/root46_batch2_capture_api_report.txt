可确认的顶层行为：

2. 白名单地图路径输出“在白名单地图, 停止引怪”，将捕获状态设置为 IDLE 并返回。
3. IDLE 路径进入扫描阶段，调用捕获的扫描/日志辅助函数，准备怪物列表。

6. ATTACKING 路径逐项检查目标是否死亡或离开视野；有效目标调用捕获的攻击辅助函数；所有目标失效后切换 IDLE。

三、数值循环核验
root/46 中出现两处 OP_412：
- PC=313：OP_412 A=3, B=166
- PC=405：OP_412 A=3, B=359
阶段三 opcode reference 对 OP_412 的解释器语义为：以寄存器 A 为循环变量，步长取 T[A+2]，上限取 T[A+1]；递增后判断正/负步长边界，满足条件时把当前值写到 T[A+3] 并跳转到 B。

因此，PC=313 与 PC=405 是数值 for-loop 的回边检查点，而不是普通比较语句。恢复循环时必须同时保留循环变量、上限、步长和 body 临时变量寄存器，不能简单改写成 ipairs 循环。
