## 实际合入主恢复源码

### 1. GetStorageItemData（root.children[1] / legacy root/2）

- 77条指令、16常量、无子原型、固定参数函数。
- root PC71创建闭包并捕获父T[4]。
- PC1-PC6：建立空数组；NPCStorageProxy缺失时直接返回空数组。
- PC7-PC17：读取最大页数并初始化1..maxPage循环。
- 每页调用GetStorageDataByPage(page)；仅table页数据经ipairs/table.insert追加。
- 页数据truthy时取长度，假值按0处理。
- 每轮读取GUIDefine.STORAGE_PER_PAGE_MAX；假值时回退global.MMO.NPC_STORAGE_MAX_PAGE。
- 每轮调用GetOpenSize；按 `openSize - (page - 1) * perPageMax` 计算当前页开放上限，并限制不超过单页上限。
- 当前页上限大于0时，累加“页上限 - 页数据长度”。
- 最后将 `仓库总可用格子: ` 与tostring(availableSlots)拼接，传给捕获的父T[4]回调，再返回storageItems。
- 回调真实业务身份未由本函数原型证据证明，源码工厂参数保留为notify，不擅自命名为PrintLog或ShowLocalNotice。

### 2. PCallHelper_2（root.children[48] / legacy root/49）

- 该辅助函数及其9条指令的Nested_FriendProxy子原型此前已在主文件“代理与回调短函数_第四批.lua”中恢复；本批复核其调用关系，并复用既有实现，不重复定义。

### 3. FindBlacklistPlayer（root.children[51] / legacy root/52）

- 35条指令、5常量、无子原型、vararg_flag=1。
- root PC353创建闭包，PC354将PCallHelper_2闭包作为UP[0]捕获。
- 读取首个vararg作为targetId。
- FriendProxy或其`_blacklistData`不存在，以及targetId为假值时，返回false。
- 先按targetId查询；命中返回`true, entry.Name`。
- 未命中时调用 `SL:GetMetaValue("ACTOR_MASTER_ID", targetId)`；仅当masterActorID为真且与targetId不相等时回查黑名单。
- 回查命中返回`true, masterEntry.Name`，否则返回false。
