# 检查点 #100：四个定时器回调与 nil 占位复核

日期：2026-11-09  
范围：`Nested_SL_3`、`Nested_shiquTimer`、`Nested_dropTimer`、`Nested_TakeItems`

## 关键序列化纠正
四个函数的关闭分支都把常量 `["unknown",2]` 写入定时器字段。该结构不是Lua运行时表，而是VM dump将nil序列化时使用的占位形式。依据：
- 检查点 #1 已通过跨20个原型、23处用途交叉核实该占位代表nil。
- 本轮四个函数均在关闭调度后，将该常量写回对应timer字段。
- 因此普通Lua恢复必须写成 `timerState.xxx = nil`，不能写成 `{"unknown",2}`。
