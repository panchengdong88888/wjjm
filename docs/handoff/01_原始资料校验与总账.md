## 4. 两套原型路径命名规则（此前重复分析的根源之一）

**从现在开始统一用 JSON children 零基路径作为权威标识。** 具体写法为 `root.children[45]`，嵌套为 `root.children[46].children[0]`。不要单独写含糊的 `root/46`。

## 5. 原型与指令统计

- 根原型：412 条物理指令、109 个常量、58 个直接子原型。
- 递归原型：**110**（含 root）。
- 递归物理指令：**5580**。
- dump 中使用 356 种 opcode。
- 早期 opcode reference 只定义 OP_000..OP_411，共 412 项，缺 OP_412。
- 阶段三 corrected opcode reference 定义 413 项，覆盖到 OP_412。
- dump 中 OP_412 出现 4 次：`root/1 PC67; root/36 PC47; root/45 PC312; root/45 PC404`。

OP_412 是数值 for-loop 步进检查：循环变量 `T[A]`、步长 `T[A+2]`、上限 `T[A+1]`；递增后按步长正负检查边界，满足时写 `T[A+3]` 并跳转到 B。优先以阶段三 corrected reference 的 OP_412 定义为准。
